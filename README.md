# 🔬 MicroScan AI

MicroScan AI is an AI-powered web application that analyzes stained microscopy images using Google Gemini Vision. It helps biology and microbiology students, laboratory trainees, and researchers by providing AI-generated image interpretations, possible microorganism suggestions, and recommended confirmatory laboratory tests.

## 📌 Problem Statement

Interpreting stained microscopy images requires experience and specialized knowledge. Students and laboratory trainees often struggle to identify microorganisms and understand microscopic morphology during practical sessions.

MicroScan AI addresses this problem by allowing users to upload microscopy images and receive instant AI-powered analysis. The application provides educational explanations, suggests possible organisms based on visible morphology, and recommends laboratory tests for confirmation. This helps users learn image interpretation more effectively while recognizing that AI suggestions should always be verified through standard laboratory procedures.

## 🤖 - AI-powered analysis of uploaded stained microscopy images

The AI functionality is implemented using **Google Gemini Vision** through an **n8n Cloud workflow**.

### Workflow

1. User uploads a microscopy image.
2. The frontend sends the image to an n8n webhook.
3. n8n forwards the image to Google Gemini Vision.
4. Gemini analyzes the image using custom instructions.
5. The generated analysis is returned to the frontend and displayed to the user.

### Custom AI Instructions (System Prompt)

The AI is instructed to:

- Analyze uploaded stained microscopy images.
- Describe visible microscopic structures and morphology.
- Suggest possible microorganisms based on observed features.
- Recommend appropriate confirmatory laboratory tests.
- Explain findings using clear scientific language suitable for students.
- Avoid making unsupported or definitive diagnoses.
- Clearly mention uncertainty whenever image quality is insufficient.

## 🚀 How to Run the Project

### Clone the Repository

```bash
git clone https://github.com/rimzi55000-coder/Rimsha-s-final-ACT-Ai-project.git
```

### Open the Project

Open the project folder and launch `index.html` in a web browser.

### Requirements

- Internet connection
- Active n8n Cloud workflow
- Valid Google Gemini API configured in n8n

Upload a microscopy image and click **Analyze Image** to receive the AI-generated report.

---


## 🔒 Security

The application does not expose the Google Gemini API key in the frontend. API requests are securely handled through an n8n Cloud workflow.
